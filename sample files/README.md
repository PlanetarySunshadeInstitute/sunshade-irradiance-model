# Sample Files

This folder contains a matched input/output pair illustrating the full pipeline.

**Input** — `constellation_B2_7070crafts_2026-04-15.mat`  
A constellation definition file generated by the constellation generator. Contains spacecraft positions and orbital parameters. The `_preview.png` is a visualization of the constellation geometry.

**Output** — `L1-RX-2026-04-17-001.nc`  
The corresponding irradiance output file calculated by the MATLAB sunshade model from the above input. The `.png` is a visualization of the resulting shade pattern.

For full details on file formats and the pipeline, see the main [README](../README.md).
